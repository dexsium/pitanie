# Отчёт о каталоге продуктов и блюд

Сформирован скриптами `tool/catalog/` из официальных выгрузок USDA FoodData Central
(общедоступные данные, CC0). Числа ниже — реальный результат запуска, а не оценка.

## Что импортировано (assets/catalog/import_report.json)
| Источник | Записей в выгрузке | Импортировано | Пропущено |
|---|---|---|---|
| USDA SR Legacy (2018-04), продукты | 7 793 | **7 793** | 0 |
| USDA FNDDS 2021–2023 (2024-10-31), готовые блюда | 5 432 | **5 431** | 1 (нет значений) |
| **Итого в каталоге** | 13 224 | **13 224** | |

Размер вшитой базы: ~4,3 МБ. Всё работает без интернета.

## Правила данных
- Значения на 100 г съедобной части, как в выгрузке; калории из нутриента 208
  (при отсутствии — Atwater 957/958; таких записей не было).
- Запись без калорий, белков, жиров или углеводов в каталог не берётся, нули не подставляются.
- Невозможные значения (Б+Ж+У > 100 г, калории > 902) отбрасываются (таких не оказалось).
- `verified = true` означает «число из официального справочника USDA», а не лабораторную проверку.
- Прежние ориентировочные продукты (seed) остаются с пометкой «Ориентировочные значения».
- Импорт идемпотентен по паре (источник, идентификатор источника); записи и дневник
  пользователя не затрагиваются. Значения в дневнике хранятся снимком на момент добавления.

## Сверка с оригиналом
`python tool/catalog/verify_sample.py ...` — 20 случайных строк (seed 7: продукты и блюда),
независимый разбор исходных CSV: **расхождений 0**.

## Исправление исходного скрипта из архива
`import_usda.py` из присланного ZIP отбрасывал все продукты USDA: он ждал тип `sr_legacy`,
а в выгрузке стоит `sr_legacy_food` (результат: 0 строк USDA). Вместо него добавлен
`tool/catalog/build_catalog.py` (SR Legacy + отдельный адаптер FNDDS: в FNDDS
`nutrient_id` совпадает с номером нутриента).

## Переводы
Название USDA по умолчанию английское. Перевод — `tool/catalog/translate_ru.py` по глоссарию
`glossary_ru.json` (основа + уточнения, согласование по роду): принимается только полностью
покрытое название, иначе остаётся английским.
- Переведено: **499 из 13 224 (3,8 %)**. Остальные 12 725 — только английские.
- Поиск по-русски работает шире: русская основа («курица», «говядина»…) добавлена в ключ
  поиска у 7 686 записей, хотя их название остаётся английским.
- Расширение: `translate_ru.uncovered()` показывает, каких слов не хватает; добавлять в
  глоссарий и пересобирать каталог.

## Open Food Facts
Независимый источник по штрихкодам, только с согласия пользователя и только штрихкод в запросе.
Нутриенты проверяются (`validateOffNutrients`), невозможные отклоняются, расхождение калорий
с БЖУ даёт предупреждение; энергия в кДж пересчитывается в ккал. Атрибуция и лицензия ODbL
показываются в диалоге и в настройках; запись сохраняется как личная копия.

## Что не сделано / ограничения
- Переведено лишь 3,8 % названий; полный перевод — отдельный проверяемый процесс.
- Записи брендов Open Food Facts не загружаются массово, только по штрихкоду.
- В SR Legacy есть позиции McDonald's, Burger King, KFC (меню США, 2018 и старше); данных
  Ростикс, «Вкусно — и точка», Додо Пиццы в USDA нет.
- Состояние продукта («сырой», «варёный»…) определяется по словам в названии USDA.
- Вес порции берётся из первой порции USDA; выбор из нескольких порций в интерфейсе не сделан.
