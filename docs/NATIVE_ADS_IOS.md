# Нативная реклама Яндекса (РСЯ) в планировщике, iOS

## Что сделано
Настоящий нативный формат на официальном Yandex Mobile Ads SDK 8 через собственное платформенное представление Flutter. Баннером формат не заменялся. Реклама подключена только на iOS: блоки в РСЯ созданы для iOS-приложения, на Android реклама не показывается.

## Версии
- Yandex Mobile Ads SDK для iOS: 8.6.x (`~> 8.6.0` в podspec, `upToNextMinor(from: "8.6.0")` в Swift Package). Та же версия, что у официального плагина `yandex_mobileads` 8.6.0: второго SDK нет, оба плагина подтягивают один пакет.
- iOS: минимум 15.0 (SDK), проект собирается с 15.5. Flutter 3.47.2.
- Рекламный SDK инициализирует официальный плагин (`YandexAds.initialize()` в `YandexAdProvider.buildAd`); нативная часть повторно не инициализирует.

## Архитектура моста
- **Dart (приложение, `lib/features/ads/`)**
  - `yandex_native_ad.dart`: виджет `YandexNativeAd` на `UiKitView` (тип `pitanie/native_ad`). Объявление запрашивается один раз при появлении виджета, а не при перестройках.
  - `native_ad_controller.dart`: состояния `idle / loading / loaded / failed / disposed`, события, одна повторная попытка через 30 секунд только пока виджет на экране, высота карточки по сообщению из iOS.
  - `native_ad_config.dart`: идентификаторы блоков и переключатель теста.
  - `yandex_ad_provider.dart`: для размещения «Планировщик» возвращает `YandexNativeAd`; интеграция с лимитами частоты и счётчиками уже существующей системы (`AdSlot`, `AdsService`) без изменений.
- **iOS (плагин `packages/pitanie_native_ads/ios`, Swift)**
  - `PitanieNativeAdsPlugin` регистрирует фабрику `PitanieNativeAdFactory` (`FlutterPlatformViewFactory`).
  - `PitanieNativeAdPlatformView` (`FlutterPlatformView` + `NativeAdDelegate`): `NativeAdLoader.loadAd(with:options:completion:)`, `AdRequest(adUnitID:)` без таргетинга и данных пользователя, `try ad.bind(with:)`, ссылки на загрузчик и объявление хранятся на время жизни представления, в `deinit` всё освобождается. Загрузка стартует по команде `load` из Dart, чтобы события не терялись. Все вызовы SDK в главном потоке.
  - `PitanieNativeAdView` (наследник `NativeAdView`): карточка в стиле приложения (белый фон, скругление 18, фиолетовая кнопка действия, поддержка тёмной темы и динамического шрифта). Связаны обязательные компоненты: заголовок, домен, дисклеймер, метка «Реклама» (`sponsoredLabel`), кнопка обратной связи, кнопка действия, медиа (не меньше 160 высотой), иконка и цена; плюс описание, иконка сайта и число отзывов. Метку «Реклама» выводит сам SDK; свою над карточкой слот не рисует.
- Каналы: `pitanie_native_ad.<id>`; события `loading`, `loaded` (высота), `failed`, `bindFailed`, `impression`, `click`.

## Где задаётся блок и режим
`lib/features/ads/native_ad_config.dart`:
- рабочий блок `kNativeAdProductionUnitId = 'R-M-20382283-1'`;
- демонстрационный блок `kNativeAdDemoUnitId = 'demo-native-app-yandex'` (реклама приложений);
- переключатель `kNativeAdUseDemo` (по умолчанию `true` на время проверки в TestFlight). Перед коммерческим запуском поставьте `defaultValue: false` или соберите с `--dart-define=NATIVE_AD_DEMO=false`.

## Конфиденциальность
В запрос уходит только идентификатор блока. Возраст, пол, рост, вес, питание, пульс, сон, тренировки и данные Здоровья не передаются, таргетинг не задаётся, согласие на персонализацию не выдаётся.

## Что проверено
- Dart: анализ без предупреждений, тесты контроллера (состояния, повтор один раз, показ только после загрузки, игнорирование событий после удаления, ограничение высоты, настройки режима) и размещения. 
- Сборка CI iOS добавляет проверку наличия `pitanie/native_ad` и Yandex SDK в IPA.

## Что НЕ проверено (нужен запуск на iPhone)
- Компиляция Swift-кода и работа на устройстве: Swift собирается только в CI (macOS), локально среды нет. Названия свойств и методов сверены с документацией Яндекса для SDK 8 и с кодом официального плагина; методы делегата `NativeAdDelegate` (`nativeAdDidClick`, `nativeAd(_:didTrackImpression:)`) названы по образцу остальных форматов SDK и не подтверждены документацией: если их имена не совпадают, события клика и показа в Dart не придут, но SDK продолжит учитывать показы у себя.
- Загрузка и отображение объявлений, видео, клик, работа без интернета, сворачивание, утечки памяти, отсутствие дублирующих запросов, проверка встроенной диагностикой SDK (`YandexAds.enableVisibilityErrorIndicator`).
- Рабочий блок `R-M-20382283-1`: что он создан именно как нативный для приложения и разрешён, видно только в кабинете РСЯ.
- Android не реализован (реклама только для iOS).
