# Этап 2. Архитектура здоровья (отчёт)

## Изменённые файлы
- `lib/database/database.dart`: схема v5 (только добавление столбцов), методы импорта веса, сверки удалений, объединения с весами приложения.
- `lib/features/health_integration/health_service.dart`: новые типы, чтение по одному типу, вес, состав тела, происхождение записей, сверка удалений.
- `lib/features/health_integration/devices_page.dart`: экран «Источники здоровья».
- `lib/features/dashboard/day_data.dart`: выбор предпочтительного источника (`mainSourceOf`, `singleSource(preferred:)`).
- `lib/features/sleep/sleep_page.dart`, `lib/features/wearables/heart_rate_page.dart`, `heart_zones_page.dart`: учитывают выбранный источник.
- `lib/features/scale/scale_controller.dart`: взвешивание с весов не дублирует уже импортированное из Здоровья.
- `lib/features/settings/backup_service.dart`: копии старого вида восстанавливаются (значения по умолчанию для новых полей).
- Тесты: `health_import_test.dart`, `sources_page_test.dart`, правки `main_source_test.dart`, `catalog_test.dart` (миграция проходит и через шаг v5).

## Что НЕ сделано в этом этапе (честно)
- **Фоновая синхронизация.** Требует нативного кода: BGTaskScheduler на iOS и WorkManager на Android. Сейчас синхронизация идёт при запуске и возврате в приложение. Выносим в отдельный шаг, когда решим, какие права и риск сборки допустимы.
- **Инкрементальные токены.** В пакете `health` есть токены изменений только для Android, для iOS нет. Использована единая сверка окна «с прошлой синхронизации минус 2 дня», она корректно обрабатывает правки и удаления, но не токены.
- **Удаление тренировок.** Сверка удалений для тренировок не делается (в таблице нет платформы).
- **Отдельный график состава тела.** Данные сохраняются (жир и безжировая масса прикрепляются ко взвешиванию), отображение относится к этапу «Статистика веса».
- **Проверка на устройствах.** Работа HealthKit и Health Connect на реальных телефонах не проверена. Единицы измерения процента жира (доля или проценты) обработаны эвристикой (значения ≤ 1 умножаются на 100); подтвердить на устройстве.

## Риски
- В Health Connect новые категории запросятся повторно; если пользователь откажет, они помечаются «нет доступа».
- Вес из Здоровья теперь попадает на график веса и в расчёты плана; ручные записи не изменяются.
