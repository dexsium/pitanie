# Этап 7. Реклама (отчёт)

## Решение
Приложение собирается для личного использования, рекламная сеть не выбрана. Поэтому сделана **архитектура подключения рекламы, а сама сеть и её SDK не добавлены**. Пока сеть не подключена, реклама не показывается, ничего не запрашивается и никакие данные никуда не уходят. Основные функции бесплатны и от рекламы не зависят, платных подписок и покупок нет.

## Подключена реклама Яндекса (РСЯ)
Используется официальный плагин `yandex_mobileads`. Блоки из кабинета РСЯ:
| Место | Блок | Формат |
|---|---|---|
| Главная | `R-M-20382283-2` | баннер |
| Статистика | `R-M-20382283-3` | баннер |
| Планировщик | `R-M-20382283-1` | нативный: **во Flutter-плагине Яндекса не поддерживается**, поэтому не используется |

- Запрос к РСЯ содержит только идентификатор блока: без возраста, пола, местоположения и данных приложения. Согласие на персонализацию не выдаётся (`setUserConsent` не вызывается), то есть показывается неперсонализированная реклама.
- Подпись «Реклама» и учёт показа появляются только после успешной загрузки объявления. При ошибке или отсутствии объявления блок исчезает, ошибка учитывается, после нескольких ошибок подряд размещение отключается на час.
- Идентификаторы блоков общие для Android и iOS. Если в кабинете РСЯ для iOS заведено отдельное приложение с другими блоками, для iOS нужно будет добавить их идентификаторы.
- В планировщике пока рекламы нет: нужно создать там **баннерный** блок и передать его идентификатор.
- Рекламные блоки в этом списке нужно показывать только на реальных устройствах: в РСЯ новые приложения и блоки могут работать не сразу (модерация), до этого объявлений не будет (блок остаётся пустым).

## Заглушки
Заглушка `PlaceholderAdProvider` в коде остаётся (её можно подставить через `adProviderProvider`, чтобы посмотреть вид рекламных мест без сети). Раньше вместо сети работала она: серый блок «Здесь будет реклама» с подписью «Реклама» на главной (баннер), в статистике (баннер) и в планировщике (блок 120 пикселей). Заглушка ничего не запрашивает из сети, не подчиняется лимитам и не попадает в счётчики. Чтобы убрать её, достаточно заменить `adProviderProvider` на `NoAdProvider` или на реализацию настоящей сети.

## Что сделано (`lib/features/ads/`)
- **Размещения** (`AdPlacement`): баннер на главной, баннер в статистике, нативный блок в планировщике, необязательная видеореклама за бонус (`bonusRewarded`, форматы banner / native / rewarded). Полноэкранной рекламы нет, показов после добавления еды или воды нет.
- **Интерфейс сети** (`AdProvider`): чтобы подключить сеть, нужно реализовать `buildAd(размещение)` и подменить `adProviderProvider`. Сети передаётся только название размещения: данные о здоровье, весе, питании, пульсе и сне в интерфейс не входят.
- **Рекламное место** (`AdSlot`): занимает место только если пользователь согласился, лимиты не исчерпаны и сеть вернула объявление; подписано «Реклама»; при пустом ответе или сбое SDK место пустое и ошибка учитывается. Без подключённой сети ничего не проверяется и не запрашивается.
- **Отключение:** по решению владельца приложения у пользователя нет настройки отключения рекламы и нет собственного экрана согласия. Реклама показывается, когда сеть подключена и не превышены лимиты. Согласие там, где оно требуется законом (например, ЕС и Великобритания), должна запрашивать платформа согласия выбранной сети; это нужно будет настроить при подключении сети.
- **Ограничение частоты** (`AdsService.decide`): минимум 120 секунд между показами размещения и до 12 показов в сутки (значения по умолчанию, удалённо нельзя ослабить ниже 30 секунд и выше 50 в сутки).
- **Пауза при отсутствии объявлений:** после 3 ошибок подряд размещение отключается на 60 минут.
- **Учёт:** показы и ошибки по размещениям за день, хранятся 14 дней, видны в настройках.
- **Удалённые настройки размещений:** если указать https-адрес (`ads_config_url` в настройках приложения), приложение раз загрузит JSON с включёнными размещениями и лимитами. Запрос не содержит данных пользователя, при ошибке остаются прежние настройки. Адреса в интерфейсе нет, это задел для будущей сети.
- **Тесты** (`ads_test.dart`): реклама разрешена по умолчанию и не отключается, интервал и дневной лимит, отключённое размещение, пауза после ошибок, счётчики, разбор удалённых настроек с защитой, загрузка только по https, поведение места без сети, с объявлением, с пустым ответом и сбоем SDK.

## Как подключать сеть позже (для вас и для меня)
1. Выбрать сеть и завести аккаунт: решение и юридические действия за владельцем приложения. Из России доступность сетей разная (например, Google AdMob с 2022 года ограничивал показ и выплаты в России, актуальное состояние нужно проверить; рассмотреть российские сети). Не нужно считать это окончательным: условия меняются.
   Отсутствие возможности отключить рекламу и отсутствие согласия пользователя могут не соответствовать правилам магазинов и законов о персональных данных в части согласия; это нужно проверить до публикации.
2. Добавить SDK и идентификаторы приложения в Android и iOS (в проекте платформенные папки создаются в CI, правки делать через `tool/setup_platforms.py`), реализовать `AdProvider`.
3. Для iOS: описание использования данных и, если сеть отслеживает пользователя, запрос ATT; в App Store Connect заполнить «Конфиденциальность приложения». Для Google Play: раздел «Безопасность данных». Для Европы и Великобритании: платформа согласия сети (например, UMP).
4. Никогда не отправлять сети данные из базы приложения; по возможности запрашивать неперсонализированные объявления.
5. Проверить требования магазинов к рекламе (подпись «Реклама», нет вводящих в заблуждение кнопок, нет рекламы поверх критичных элементов).

## Bluetooth-библиотека и реклама
Для `flutter_blue_plus` указана лицензия `nonprofit` (личное использование). Пока приложение личное и бесплатное, это допустимо. Если приложение будет публично распространяться с рекламой (коммерческое использование), лицензию нужно пересмотреть: купить коммерческую или перейти на библиотеку с лицензией BSD (например, `flutter_reactive_ble`).

## Ограничения
- Реальной рекламы нет и быть не может, пока не подключена сеть. Проверить показ баннера на устройстве сейчас нельзя.
- Проверка требований App Store, Google Play и выбранной сети невозможна до выбора сети.
